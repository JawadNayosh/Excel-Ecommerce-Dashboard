E-Commerce Analytics Dashboard (Excel)
🔍 Overview

A fully interactive Excel dashboard built to analyze e-commerce sales, customer behavior, product performance, and shipping trends. This project shows how powerful Excel can be for business intelligence and storytelling with data.

# Key Features
13-week sales trend analysis
Customer demographics & gender split
Popular products overview
Purchase behavior heatmap
Shipping time insights
Customer satisfaction scores
Interactive slicers & clean visual design

# Skills Used
Pivot tables & pivot charts
Data cleaning
Slicers
Conditional formatting
Dashboard design

Purpose
This project demonstrates my ability to build clear, insightful dashboards using Excel — a useful sample for data analyst and BI roles.
